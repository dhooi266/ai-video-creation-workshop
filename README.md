# AI-Powered Video Creation Mastery — Corporate Landing Page

Evergreen landing page introducing the 2-day AI video workshop to **corporate clients**, by D Action Consultancy & Services Sdn Bhd.

No dates and no prices — so the page stays accurate between runs and can be sent to any company at any time. Enquiries go to david@daction.com for a tailored proposal.

> For the public-run version with fixed dates and seat pricing, see [ai-video-creation-mastery](https://github.com/dhooi266/ai-video-creation-mastery).

## What's here

A single self-contained page — no build step, no dependencies, no framework.

```
index.html           the whole page (HTML + CSS + inline SVG icons and artwork)
cover.png            hero banner
og-image.jpg         1200x630 link preview thumbnail (WhatsApp, LinkedIn, Facebook)
dac-logo.png         D Action Consultancy logo
david-hooi.jpg       trainer portrait
thumb-ad.jpg         sample advertisement video thumbnail
thumb-mv.jpg         sample music video thumbnail
thumb-shortfilm.jpg  sample short film thumbnail
```

Fonts (Archivo, Spectral, IBM Plex Mono) load from Google Fonts. Everything else is local.

## Page structure

1. Hero — cover banner, workshop positioning, at-a-glance card
2. Programme overview — the business case, plus "Why companies run this" and "How we deliver it"
3. What you'll gain — six capability cards
4. Showreel — three finished sample videos
5. Learning outcomes
6. Full 2-day agenda, hour by hour
7. Coach profile — David Hooi
8. Who it's for and delivery requirements
9. Request-a-proposal CTA

## Running it

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```
